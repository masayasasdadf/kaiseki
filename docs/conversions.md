# コンバージョン設定ガイド

## コンバージョンとは

「お問い合わせ完了」「購入完了」「資料ダウンロード」など、
サイトの目標として設定したアクションが達成されること。

## 設定方法（ノーコード）

管理画面 > コンバージョン > 「成果を追加」ボタン

### タイプA: URLベース（最も簡単）

サンクスページへの到達で計測。

設定例:
- パス: `/thanks`
- 一致タイプ: 含む（contains）

動作: 訪問者が `/thanks` を含むURLを閲覧したら自動でカウント。

### タイプB: クリックベース

特定ボタンのクリックで計測。

設定例:
- セレクタ: `#contact-submit`

HTMLに `data-track` を追加するだけでも計測可能:
```html
<button data-track="contact_submit">送信する</button>
```

### タイプC: フォーム送信

フォーム送信完了で計測。

設定例:
- セレクタ: `#inquiry-form`

## 重複除外

同一セッション × 同一コンバージョン名 = 1回のみカウント。
（ページリロードや戻るボタンで二重カウントされない）

## 手動コンバージョン送信

```javascript
window.kaiseki.conversion('purchase_complete', {
  value: 5000,
  product: 'premium_plan'
});
```

## 監査ログ

CV設定の作成・変更・削除はすべて `audit_logs` テーブルに記録。
