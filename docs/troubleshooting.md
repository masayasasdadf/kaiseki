# トラブルシューティング

## データが計測されない

### チェックリスト

1. SDKスニペットが正しく設置されているか
   - `data-project` にプロジェクトキーが設定されているか
   - `</body>` タグの前に設置されているか

2. ブラウザコンソールでエラーを確認
   ```
   window.kaiseki.debug()
   ```

3. ネットワークタブで `/api/ingest` へのリクエストを確認
   - 200 OKが返っているか
   - エラーの場合はレスポンスボディを確認

4. 設定 > 許可ドメインを確認
   - 空の場合はすべて許可
   - ドメインを設定した場合、アクセスしているドメインと一致しているか

### よくあるエラー

| エラー | 原因 | 解決策 |
|-------|------|--------|
| 401 Invalid project key | プロジェクトキーが間違っている | 設定画面で正しいキーを確認 |
| 429 Too many requests | レート制限 | 短時間に大量リクエストを送信していないか確認 |
| CORS エラー | ドメイン設定の問題 | 設定 > 許可ドメインを確認 |

## チャネルが「Direct」になる

UTMパラメータが付いていない場合はDirectになります。

Google広告の場合: gclid が自動付与される（手動タグ付け設定が必要な場合あり）

## コンバージョンがカウントされない

- URLベース: パスパターンが正しいか確認（`/thanks` 等）
- 同一セッション内での重複は除外される仕様
- ブラウザの `sendBeacon` が動作しているか確認

## 本番環境の設定確認

```bash
# 環境変数の確認
node -e "require('./lib/env')"

# DBへの接続確認
npx prisma db push --preview-feature
```

## SSE（ライブイベント）が表示されない

- Vercel無料プランではSSEのタイムアウトが10秒
- Pro プランへのアップグレードで解消
- ローカル開発では問題なく動作する
